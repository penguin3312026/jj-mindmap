🛠️ 作者发布页

只有你有这个页面。用它把导图更新发布到线上，所有拿到链接的人打开即同步。读者请用不带 /admin.html 的主链接（或 ?reader=1 阅读版）。

① 解锁（发布密码）

密码错误

② 选择导图 JSON

③ 生成发布包（自动 rev+1）

生成后版本号自动 +1。把下面两个文件上传到同一目录（七牛空间根目录），全员打开即见新版本，且同步按钮会闪烁提醒。

④ 发布到线上（七牛云）

把上面生成的 data.js 和 version.js 两个文件上传到七牛空间同一目录（建议根目录）即可。两种上传方式：
A. 控制台拖拽（零门槛，推荐首次用）
1. 登录七牛云控制台 → 对象存储 → 你的空间（需设为公开）
2. 点「上传文件」，把 data.js 和 version.js 一起拖进去（同名覆盖）
3. 确认 index.html 也已在该空间可访问（见「手机访问地址」里的七牛链接）
4. 完成！所有打开你链接的人，1 分钟内同步按钮自动闪烁提醒更新。
B. qshell 命令行（配置一次，以后一行命令）
1. 下载 qshell，配置 ~/.qshell/account.json（填 AccessKey / SecretKey）
2. 把下面的命令存成 publish.sh，每次发布后运行：
qshell fput 你的空间名 data.js data.js
qshell fput 你的空间名 version.js version.js
3. 首次需把 index.html 也上传一次，之后只更新 data.js / version.js 即可。
